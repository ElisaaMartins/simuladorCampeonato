# Simulador de classificação de umcampeonato esportivo
Projeto prático da disciplina de ALC2.
Consiste em criar um simulador de campeonatos, que se inicia com pontos corridos e depois com chaveamento. As regras serão baseadas no campeonato do brasileirão de 1990, e usaremos a linguagem C++.
Além de aplicar programação modular, manipulação dearquivos, estruturas e recursividade, conceitos aprendidos durante a disciplina.
